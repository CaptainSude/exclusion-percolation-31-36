# v1.0.0 — Paper and Lean verification

Exceptional times for rate-one nearest-neighbor exclusion percolation on the triangular lattice have Hausdorff dimension **31/36**, almost surely in every nonempty time interval.

This release contains the six-page paper, its LaTeX source, and the accompanying Lean development. The PDF and standalone Lean archive are attached below.

The completed verification checks **443 Lean files** and audits **8,241 declarations**, including **6,231 theorems**, using Lean **4.34.1** and mathlib revision `d13f23b723b8a846827a245b89c10fc7d3f11612`.

The repository README links the main theorem, proof guide, literature inputs, build instructions and full verification record.
